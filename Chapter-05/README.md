# 🌊 浮标数据基于 SVR 的海浪高度预测项目  

本项目基于真实浮标观测数据（46221、46251 两个站点），利用**滑动时间窗口 + 支持向量回归（SVR / LinearSVR）** 构建海浪有效波高（WVHT）的短时序预测模型。

预测任务：  
> 使用过去 **24 小时** 的 WVHT + 风场数据（u10、v10），预测 **下一小时** 的 WVHT。

模型采用 **标准化 + LinearSVR**，高效适用于超 4 万条大规模样本，能够在数秒内完成训练。

# 🧩 功能概述

本项目主要包括三个部分：

1. **数据预处理**  
   - 时间序列重采样（1h）  
   - 缺测线性插值  
   - 风速风向提取  
   - 构造 24 小时滑动时间窗口

2. **特征构造**  
   - 输入向量维度为 `24h × 3 个变量 = 72 维`  
   - 目标为下一小时的 WVHT 值

3. **SVR 模型训练与性能评估**  
   - 使用 StandardScaler + LinearSVR  
   - 输出 RMSE / MAE / R² 等性能指标

# 📊 一、数据预处理（`svr.py`）

## 1. 数据来源
浮标 CSV 文件包含如下字段：

| 字段 | 含义 |
|------|------|
| DateTime | 浮标观测时间 |
| WVHT | 有效波高（m） |
| u10 | 10m高度风东西分量 |
| v10 | 10m高度风南北分量 |

示例（46221.csv）：

```
DateTime,u10,v10,WVHT
2019-01-01 00:00,3.048406,-2.101060,1.26
2019-01-01 01:00,2.385077,-2.524526,1.34
...
```

## 2. 时间统一化与缺测插值
项目对数据进行以下处理：

✔ 以 `1h` 频率重采样  
✔ 对缺时段进行线性插值  
✔ 开头和结尾缺失使用前向/后向填补

## 3. 滑动窗口构造（24 小时 → 下一小时）
输入特征：

\[
X_t = [WVHT_{t-23:t}, u10_{t-23:t}, v10_{t-23:t}]
\]

维度：

```
history_len = 24
feature_dim = 24 × 3 = 72
```

输出标签：

\[
y_t = WVHT_{t+1}
\]

最终样本数（46221 浮标）：

```
X.shape = (43800, 72)
y.shape = (43800,)
```
